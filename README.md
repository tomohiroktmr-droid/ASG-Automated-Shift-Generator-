# 🍽️ プッチョン シフト自動集計ツール

飲食店「プッチョン」のアルバイトスタッフが Googleカレンダーに入力したシフト希望を、
**店長のスプレッドシートに自動でまとめる** Google Apps Script（GAS）ツールです。

> スマホ・パソコン不問。スタッフはいつも通りカレンダーに予定を入れるだけ。
> 店長はボタン1つで全員分のシフト希望を一覧表示できます。

## 1. このツールでできること

| 機能 | 説明 |
|------|------|
| シフト希望の自動収集 | スタッフが各自のGoogleカレンダーに入力したシフト希望を自動取得 |
| 一覧表への出力 | スタッフ名・日付・開始時間・終了時間をスプレッドシートに書き出し |
| 期間指定 | 来月分など、好きな期間を指定して取得 |
| 毎月自動実行 | トリガーを設定すれば、毎月決まった日に自動集計 |

---

## 2. 全体の流れ

```
【スタッフ】
  自分のGoogleカレンダーに「シフト希望」の予定を入力する
  ↓ カレンダーを店長と共有する（初回のみ）

【店長】
  このツールを導入する（初回のみ）
  ↓
  「シフトを集計する」を実行
  ↓
  スプレッドシートに全員分のシフト希望が一覧表示される 🎉
```

## 3. 事前準備：スプレッドシートを作る

### 3-1. 新しいスプレッドシートを作成する

1. **[Google スプレッドシート](https://sheets.google.com)** を開きます
2. 左上の **「＋ 新しいスプレッドシート」** をクリックして新規作成します
3. ファイル名を「**プッチョン シフト管理**」などわかりやすい名前にします

### 3-2. 必要なシートを自動作成する（コード貼り付け後に実行）

> ⚠️ このステップは **STEP 5（初回承認）の後** に実行します。
> まずは次の「コードの貼り付け」へ進んでください。

コードを貼り付けて承認が完了すると、メニューから以下のシートを一括作成できます。

| シート名 | 役割 |
|---------|------|
| `スタッフ管理` | スタッフ名とカレンダーIDを登録する一覧表 |
| `設定` | 集計したい期間（開始日・終了日）を入力する |
| `シフト集計` | 集計結果が自動で書き出される出力先 |

**各シートの見た目（完成イメージ）:**

**スタッフ管理シート**

| A列（スタッフ名） | B列（カレンダーID） |
|:----------------|:----------------|
| 山田 太郎 | yamada@gmail.com |
| 佐藤 花子 | sato@gmail.com |
| 鈴木 次郎 | suzuki@gmail.com |

**設定シート**

| A列（ラベル） | B列（入力欄） |
|:------------|:------------|
| 取得開始日 | 2026/04/01 |
| 取得終了日 | 2026/04/30 |

**シフト集計シート（出力例）**

| スタッフ名 | 日付 | 開始時間 | 終了時間 | イベント名（備考） |
|:---------|:----|:--------|:--------|:--------------|
| 山田 太郎 | 2026/04/05 | 17:00 | 22:00 | シフト希望 |
| 佐藤 花子 | 2026/04/05 | 11:00 | 16:00 | 遅番希望 |
| 鈴木 次郎 | 2026/04/06 | 終日 | 終日 | シフト入れます |

## 4. Google Apps Script にコードを貼り付ける

### 4-1. Apps Script エディタを開く

1. スプレッドシートのメニューバーから **「拡張機能」** をクリックします
2. **「Apps Script」** をクリックします
3. 新しいタブで Apps Script エディタが開きます

### 4-2. 既存のコードを削除する

エディタを開くと、最初から以下のようなコードが入っています。

```javascript
function myFunction() {

}
```

このコードを**すべて選択して削除**します（`Ctrl+A` → `Delete`）。

### 4-3. このリポジトリのコードを貼り付ける

1. このリポジトリの **`Code.gs`** ファイルを開きます
2. 内容をすべてコピーします（`Ctrl+A` → `Ctrl+C`）
3. Apps Script エディタに貼り付けます（`Ctrl+V`）

### 4-4. 保存する

- 画面上部の **フロッピーディスクアイコン（💾）** をクリックします
- または **`Ctrl+S`** を押します
- 「プロジェクトを保存しました」と表示されれば成功です

## 5. 初回の「承認」を行う

コードの貼り付けが完了したら、**スプレッドシートに戻り**ページを再読み込み（`F5`）します。

### 5-1. カスタムメニューの確認

メニューバーに **「🗓 シフト管理」** が追加されているのを確認します。

```
ファイル  編集  表示  挿入  表示形式  データ  ツール  拡張機能  ヘルプ  🗓 シフト管理
```

### 5-2. 初期設定を実行して承認を行う

1. **「🗓 シフト管理」** → **「シートの初期設定」** をクリックします
2. 承認を求めるダイアログが表示されます → **「続行」** をクリックします

### 5-3. 承認画面の進み方（初回のみ）

Googleアカウントの選択画面が表示されます。

```
STEP A: 店長のGoogleアカウントを選択する
   ↓
STEP B: 「このアプリはGoogleによって確認されていません」という警告が出る
   ↓
STEP C: 左下の「詳細」をクリックする
   ↓
STEP D: 「プッチョン シフト管理（安全ではないページ）に移動」をクリックする
   ↓
STEP E: 右下の「許可」をクリックする
```

> **なぜ警告が出るの？**
> Googleに審査登録されていない個人作成のスクリプトには、この警告が必ず表示されます。
> ご自身が作成・貼り付けたコードなので、安全に使用できます。

### 5-4. 初期設定の完了確認

承認後、「✅ 初期設定完了」ダイアログが表示され、
スプレッドシートに **「スタッフ管理」「設定」「シフト集計」** の3シートが作成されます。

## 6. スタッフにカレンダーを共有してもらう

このツールは、**店長アカウントがスタッフのカレンダーを読み取る**仕組みです。
そのため、スタッフ全員に以下の操作をお願いしてください。

### スタッフ側の操作手順

1. **[Google カレンダー](https://calendar.google.com)** をパソコンで開く
2. 左サイドバーの「**マイカレンダー**」の中にある、自分の名前のカレンダーにマウスを合わせる
3. 右側に現れる **「⋮（縦三点リーダー）」** をクリック
4. **「設定と共有」** をクリック
5. 「特定のユーザーまたはグループと共有する」の **「＋ ユーザーを追加」** をクリック
6. **店長のGmailアドレス**を入力する
7. 権限を **「予定の閲覧（すべての予定の詳細）」** に設定する
8. **「送信」** をクリックする

### 店長側の操作（共有招待を承認する）

スタッフが共有すると、店長のGmailに招待メールが届きます。

1. Gmailの受信トレイを開く
2. 「〇〇さんがカレンダーを共有しました」というメールを開く
3. **「このカレンダーを追加」** をクリックする
4. Google カレンダーの左サイドバーに、スタッフのカレンダーが追加されれば完了

> **スタッフ全員分、この手順を繰り返してください。**

## 7. スタッフ情報を登録する

「**スタッフ管理**」シートを開き、スタッフの情報を入力します。

| A列 | B列 |
|:----|:----|
| スタッフ名（表示名） | カレンダーID（GmailアドレスをそのままでOK） |
| 山田 太郎 | yamada@gmail.com |
| 佐藤 花子 | sato@gmail.com |

> **カレンダーIDとは？**
> ほとんどの場合、スタッフの **Gmailアドレス** がそのままカレンダーIDになります。
> （例: `yamada@gmail.com`）
> GASの初期設定で入ったサンプル行は削除して、実際のスタッフ情報に書き換えてください。

## 8. 取得期間を設定して集計を実行する

### 8-1. 期間を設定する

「**設定**」シートを開き、集計したい期間を入力します。

| セル | 入力内容 | 入力例 |
|:----|:--------|:------|
| B1 | 取得開始日 | `2026/04/01` |
| B2 | 取得終了日 | `2026/04/30` |

> 来月分を集計したい場合は、来月の1日〜末日を入力してください。

### 8-2. 集計を実行する

1. メニューの **「🗓 シフト管理」** → **「シフトを集計する」** をクリックします
2. 少し待つと「✅ 集計が完了しました」ダイアログが表示されます
3. **「シフト集計」** シートに全スタッフ分のシフト希望が一覧表示されます

**出力例:**

| スタッフ名 | 日付 | 開始時間 | 終了時間 | イベント名（備考） |
|:---------|:----|:--------|:--------|:--------------|
| 佐藤 花子 | 2026/04/05 | 11:00 | 16:00 | 遅番希望 |
| 山田 太郎 | 2026/04/05 | 17:00 | 22:00 | シフト希望 |
| 山田 太郎 | 2026/04/06 | 終日 | 終日 | 終日シフト可 |

> **注意:** 実行のたびに「シフト集計」シートはいったんクリアされ、最新データで全件書き直されます。
> 手動で追記した内容は消えますので、メモはシート外に記録しておいてください。

## 9. 毎月自動実行する（トリガー設定）

毎月決まった日（例：25日のシフト提出締め切り後）に自動集計したい場合は、トリガーを設定します。

### 9-1. トリガー画面を開く

1. Apps Script エディタを開きます（スプレッドシート → 拡張機能 → Apps Script）
2. 左側のアイコン一覧から **時計アイコン（⏰）** をクリックします
3. 「トリガー」画面が開きます

### 9-2. 新しいトリガーを追加する

1. 右下の **「＋ トリガーを追加」** をクリックします
2. 以下のように設定します:

| 項目 | 設定値 |
|:----|:------|
| 実行する関数を選択 | `runShiftExport` |
| 実行するデプロイを選択 | `Head` |
| イベントのソースを選択 | `時間主導型` |
| 時間ベースのトリガーのタイプを選択 | `月タイマー` |
| 日付 | `25` （毎月25日に集計したい場合） |
| 時刻 | `午前9時〜10時` など、営業開始前の時間帯を推奨 |

3. **「保存」** をクリックします

### 9-3. 動作確認

「トリガー」一覧に追加したトリガーが表示されれば設定完了です。
次回の実行日時が来たら、スクリプトが自動で集計を行い「シフト集計」シートを更新します。

> **「設定」シートの日付は毎月更新が必要です。**
> トリガーで自動実行する場合は、実行前に「設定」シートのB1・B2を翌月の日付に変更しておいてください。
> または、スクリプトを改修して「翌月1日〜末日」を自動計算する設定にすることも可能です。

## 10. よくあるエラーと対処法

| 症状・エラー | 考えられる原因 | 対処法 |
|:-----------|:------------|:------|
| 「カレンダーが見つかりません」 | スタッフが店長にカレンダーを共有していない | STEP 6の手順で共有・承認を行う |
| 「設定」シートに日付がない | 設定シートのB1/B2が空欄 | 開始日・終了日を入力する |
| 「スタッフ未登録」 | スタッフ管理シートにデータがない | スタッフ名とカレンダーIDを入力する |
| シフト集計シートに何も出ない | 指定期間にイベントがない | 期間を確認し、スタッフがカレンダーに予定を入力済みか確認する |
| メニューに「🗓 シフト管理」が出ない | ページの再読み込みがされていない | `F5` でページを再読み込みする |
| 承認画面でエラー | 別のGoogleアカウントでログインしている | 店長アカウントでログインし直す |
