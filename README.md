# プッチョン 統合スタッフ管理システム

Googleスプレッドシート + Google Apps Script Web App で動作する統合スタッフ管理ツールです。

---

## 機能一覧

| 機能 | 説明 |
|------|------|
| ✅ チェックリスト | フロア・ポジション・タイミング別タスク一覧。タップひとつで実施記録 |
| 📖 マニュアル連携 | 各タスクに手順メモ＋外部マニュアルURL（Googleドキュメントなど）を紐付け |
| 📊 統計 | スタッフ別・タスク別の完了率・平均所要時間を自動集計 |
| ⭐ スキルチェック | スキル項目ごとに1〜5段階評価 |
| 💰 給与査定 | チェック実施率＋スキル平均をスタッフ別にまとめた査定サマリー |
| 👥 スタッフ管理 | スタッフのフロア・ポジション・時給・入社日を管理 |
| 📋 タスク管理 | タスクの追加・編集。フロア・ポジション・タイミング別に絞り込み |
| 🗓 シフト集計 | Googleカレンダーからシフト希望を取得して集計 |

---

## セットアップ手順

### 1. Google Apps Script プロジェクトの準備

1. Googleスプレッドシートを新規作成
2. 「拡張機能」→「Apps Script」を開く
3. `Code.gs` の内容をすべて貼り付け（既存コードは削除）
4. 「＋ ファイル」→「HTML」で `WebApp` という名前のHTMLファイルを作成し、`WebApp.html` の内容を貼り付け
5. 保存（`Ctrl+S`）

### 2. 初期セットアップ

1. スプレッドシートを再読み込み（F5）
2. メニュー「🏪 スタッフ管理」→「初期セットアップ」を実行
3. 承認ダイアログが出たら「許可」を選択
4. 必要なシートが自動作成されます

### 3. Web App としてデプロイ

1. Apps Script エディタで「デプロイ」→「新しいデプロイ」
2. 種類: **ウェブアプリ**
3. アクセスできるユーザー: 「自分のみ」または「組織内のユーザー」
4. 発行されたURLをスタッフに共有（ブックマーク推奨）

### 4. スタッフ管理画面を開く

メニュー「🏪 スタッフ管理」→「管理画面を開く」またはデプロイURLに直接アクセス

## シート構成

| シート名 | 内容 |
|---------|------|
| スタッフ管理 | スタッフID・氏名・役職・フロア・ポジション・時給など |
| タスクマスタ | タスクID・名前・フロア・ポジション・手順メモ・マニュアルURLなど |
| チェック記録 | チェック実施ログ（日時・担当者・ステータス・所要時間） |
| スキル評価 | スタッフ別スキル項目の評価レベル（1〜5） |
| 設定 | 店舗名・フロア一覧・ポジション一覧・シフト取得期間 |
| シフト集計 | Googleカレンダーからのシフト集計結果 |

## スキルレベル基準

| レベル | 説明 |
|-------|------|
| 1 | 要学習（まだできない） |
| 2 | 練習中（サポートがあればできる） |
| 3 | 独力可（一人でできる） |
| 4 | 熟練（素早く・正確にできる） |
| 5 | 後輩指導可（教えられる） |

---

## フロア・ポジション設定

「設定」シートで変更できます：

- `フロア一覧`：カンマ区切りで指定（例: `2F,3F,共通`）
- `ポジション一覧`：カンマ区切りで指定（例: `ホール,ドリンク,レジ,キッチン,共通`）
